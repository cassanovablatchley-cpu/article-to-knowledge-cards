# make-knowledge-cards

一个将文章提炼为知识卡片的 Codex Skill。

## 1. 项目解决什么问题

长文章中的重点、机制、条件和结论往往分散在大量叙述、重复内容和例子之间，直接复习时很难快速抓住知识结构。

`make-knowledge-cards` 帮助用户从粘贴的文章或本地 Markdown/TXT 文件中提炼真正重要的知识点，整理成可逐张阅读、复习和自测的知识卡片。

## 2. 主要功能

- 支持直接粘贴的文章，以及本地 `.md` 和 `.txt` 文件。
- 默认生成 5–8 张卡片；原文不足以支持 5 个独立知识点时，只生成有依据的卡片并说明原因。
- 每张卡包含标题、核心知识、简明解释，以及原文例子或可依据卡片回答的自测题。
- 优先提取定义、结论、因果关系、关键机制、成立条件、决策依据和重要步骤。
- 一张卡只讲一个知识点，并删除换一种说法重复出现的内容。
- 只使用原文已有信息，不补写原文没有的数据、因果、案例或建议。
- 默认沿用原文语言，也可以按用户要求切换输出语言。
- 直接输出 Markdown 格式的知识卡片。

暂不支持网页抓取、PDF、其他文件格式、Anki 导出或图形界面。

## 3. 安装方法

把 Skill 目录复制到 Codex 的 skills 目录：

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R skills/make-knowledge-cards "${CODEX_HOME:-$HOME/.codex}/skills/"
```

重新开始一个 Codex 会话后，即可通过 `$make-knowledge-cards` 调用。

## 4. 使用方法

直接粘贴文章：

```text
使用 $make-knowledge-cards，把下面文章整理成知识卡片：

<粘贴正文>
```

指定本地 Markdown 或 TXT 文件：

```text
使用 $make-knowledge-cards，把 ./article.md 整理成知识卡片。
```

如果原文不是中文，但希望获得中文卡片，可以在请求中明确说明：

```text
使用 $make-knowledge-cards，把 ./article.txt 整理成中文知识卡片。
```

遇到网页、PDF 或其他文件格式时，请先提供正文，或转换为 `.md`/`.txt` 文件。

## 5. 输入输出示例

输入：

```text
间隔复习把学习分散到多个时间点，比一次集中复习更有利于长期记忆。
每次复习之间留出遗忘，再重新提取信息，会让记忆更牢固。
因此，与其考前连续复习数小时，不如把同样的学习时间分散到几天。
```

输出：

```markdown
> 说明：原文仅支持形成 1 个独立的重要知识点，因此未补足到 5 张。

### 1. 间隔复习强化长期记忆

**核心知识：** 把学习分散到多个时间点，比一次集中复习更有利于长期记忆。

**简明解释：** 间隔让部分信息自然遗忘，再次提取时会强化记忆。原文建议把同样的学习时间分散到几天。

**自测：** 为什么原文认为间隔复习比考前连续复习更有效？
答案：间隔后再提取信息能强化记忆，而集中复习没有留出这一过程。
```

以上为信息不足时的示例。原文包含 5–8 个独立且重要的知识点时，Skill 会按同样格式生成对应数量的卡片。
